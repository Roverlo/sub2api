# 我们的 AI 中转站客户使用指南

这份说明书是给购买或试用我们中转站服务的客户看的。你可以把它理解成：注册账号、购买或兑换额度、创建 API 密钥，然后把我们的接口接入到你的工具里。

我们的服务基于 Sub2API 搭建，核心价值是：一个网站、一个 API Key，就能更方便地使用 OpenAI、Claude、Gemini、Antigravity 等多种大模型能力。你不需要自己搭建服务器，也不需要自己维护上游账号池，更不用为了调用海外模型接口反复折腾 VPN。

> 请把文中的 `https://你的中转站域名` 替换成我们实际提供给你的网址。模型名称、套餐、倍率、价格和可用渠道，以网站后台展示为准。

> 本文不是通用 API 教程，而是按我们网站的实际页面来写：注册 `/register`，登录 `/login`，购买 `/purchase`，兑换 `/redeem`，API 密钥 `/keys`，用量 `/usage`，可用渠道 `/available-channels`，渠道状态 `/monitor`。

## 适合谁使用

- 想在国内网络环境下稳定调用大模型 API 的个人或团队。
- 想用 OpenAI、ChatGPT-5.5 / GPT-5.5、Claude、Gemini 等模型，但不想自己处理账号、网络和接口维护的人。
- 想把大模型接入 Cursor、Codex CLI、Claude Code、Gemini CLI、OpenCode、自己的程序或自动化脚本的人。
- 想用余额、订阅、兑换码和 API Key 管理团队用量的人。

## 我们中转站的优势

### 免 VPN，国内环境也能更省心调用

很多用户直接调用海外模型接口时，会遇到连不上、超时、网络不稳定、账号配置复杂等问题。使用我们的中转站后，你只需要访问我们的网站和 API 地址，请求由中转站转发到上游模型服务，日常调用更省心。

### 一个 API Key，接入多个模型和工具

你在网站的「API 密钥」页面创建一个 Key 后，就可以根据后台开放的渠道调用不同模型。网站支持的模型和渠道会在「可用渠道」里展示，例如 OpenAI / ChatGPT-5.5、Claude、Gemini、Antigravity 等，实际可用项以后台为准。

### 不需要自己维护上游账号和服务器

我们负责上游账号、调度、计费、负载均衡和接口转发。客户只需要管理自己的余额、订阅、兑换码和 API Key，不用从零部署 Sub2API，也不用自己处理服务器运维。

### 用量清楚，可控成本

后台可以查看余额、兑换记录、密钥用量、模型用量和订单记录。你可以给不同工具创建不同 Key，也可以给 Key 设置额度限制、有效期、IP 限制和速率限制，避免一个 Key 被滥用。

### 适合开发者和团队

一个账号可以创建多个 API Key。你可以按用途区分，例如：

- `cursor-work`：给 Cursor 或 IDE 插件使用。
- `codex-cli`：给 Codex CLI 使用。
- `server-prod`：给服务器或自动化任务使用。
- `team-test`：给团队测试环境使用。

## 第 1 步：打开我们的网站

1. 打开我们提供的中转站网址：`https://你的中转站域名`
2. 如果你还没有账号，进入注册页：`https://你的中转站域名/register`
3. 如果你已有账号，进入登录页：`https://你的中转站域名/login`

登录后会进入用户控制台，你可以在左侧菜单看到常用入口：

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 控制台 | `/dashboard` | 查看账户概览和快捷入口 |
| API 密钥 | `/keys` | 创建、复制、管理 API Key |
| 用量记录 | `/usage` | 查看请求、模型和费用明细 |
| 可用渠道 | `/available-channels` | 查看当前开放的模型渠道 |
| 渠道状态 | `/monitor` | 查看渠道可用性和延迟 |
| 充值/订阅 | `/purchase` | 购买余额或订阅套餐 |
| 兑换码 | `/redeem` | 使用兑换码兑换余额、并发或试用权限 |
| 我的订单 | `/orders` | 查看充值和订阅订单 |

## 第 2 步：注册账号

进入 `/register` 后，按页面提示填写信息：

1. 输入邮箱。
2. 设置密码。
3. 如果页面显示邀请码，请填写我们提供的邀请码。
4. 如果页面显示优惠码，可填写我们提供的优惠码，享受活动赠送额度。
5. 如果页面要求验证，请完成邮箱验证或人机验证。
6. 点击「创建账号」。

注册成功后会进入控制台。如果你已经有账号，直接从 `/login` 登录即可。

## 第 3 步：购买套餐或兑换额度

我们的网站支持两种常见开通方式：在线购买和兑换码。

### 方式 A：在线购买

进入 `/purchase` 页面，按页面展示选择：

1. 选择「充值」或「订阅」。
2. 如果是充值，输入充值金额。
3. 如果是订阅，选择适合你的模型渠道或套餐。
4. 选择支付方式。
5. 创建订单并完成支付。
6. 支付完成后，回到控制台或订单页确认到账。

支付和到账情况可以在 `/orders` 查看。

### 方式 B：使用兑换码

如果我们给了你兑换码，进入 `/redeem` 页面：

1. 查看页面顶部的当前余额和并发数。
2. 在「兑换码」输入框粘贴兑换码。
3. 点击「兑换」。
4. 页面显示「兑换成功」后，确认新余额、新并发或订阅权限。
5. 下方「最近活动」会显示兑换历史。

兑换码说明：

- 每个兑换码通常只能使用一次。
- 兑换码区分大小写。
- 兑换码可以增加余额、并发数或试用/订阅权限。
- 如果兑换失败，请检查是否多复制空格、是否已使用、是否过期。
- 遇到问题请联系客服，并提供兑换失败截图。

## 第 4 步：创建 API 密钥

购买或兑换成功后，进入 `/keys` 页面创建 API Key。

1. 点击「创建密钥」。
2. 给密钥起一个好识别的名字，例如 `codex-cli`、`cursor-work`、`server-test`。
3. 选择一个可用分组。分组决定这个 Key 走哪个模型渠道和费率规则。
4. 按需设置：
   - 自定义密钥：适合想自己指定 Key 字符串的用户。
   - IP 限制：只允许指定 IP 使用这个 Key。
   - 额度限制：限制这个 Key 最多可消费多少余额。
   - 速率限制：限制 5 小时、1 天或 7 天内的消费额度。
   - 密钥有效期：让 Key 到期自动失效。
5. 保存后，在密钥列表里复制 API Key。

重要提醒：API Key 等同于你的额度使用凭证。不要发到群里，不要贴到公开代码仓库，不要在截图中完整展示。

## 第 5 步：复制 API 地址

在 `/keys` 页面顶部，网站会展示 API 地址信息。如果配置了多个自定义端点，也会在这里显示。

常见填写方式如下：

| 配置项 | 你应该填写 |
| --- | --- |
| Base URL / API URL | 网站展示的 API Base URL，通常形如 `https://你的中转站域名/v1` |
| API Key | `/keys` 页面复制出来的密钥 |
| Model | `/available-channels` 或工具提示中展示的模型名 |

如果工具要求填写完整接口地址，通常使用：

```text
https://你的中转站域名/v1/chat/completions
```

如果工具要求填写 Base URL，通常填写到 `/v1` 即可：

```text
https://你的中转站域名/v1
```

## 第 6 步：使用「使用密钥」快速配置工具

在 `/keys` 页面，每个 Key 后面都有「使用密钥」按钮。点击后，网站会根据该 Key 所属分组展示对应客户端的配置示例。

常见支持场景包括：

- OpenAI / ChatGPT-5.5 渠道：Codex CLI、Codex CLI WebSocket、OpenCode 等。
- Claude 渠道：Claude Code、OpenCode 等。
- Gemini 渠道：Gemini CLI、OpenCode 等。
- Antigravity 渠道：Claude Code、Gemini CLI、OpenCode 等。

如果你不确定怎么配，优先点击「使用密钥」，复制弹窗里的命令或配置文件内容。

## OpenAI 兼容接口调用示例

下面是最常见的 OpenAI 兼容调用方式。请把域名、Key 和模型替换成你网站后台实际显示的内容。

### PowerShell 测试

```powershell
$body = @{
  model = "gpt-5.5"
  messages = @(
    @{ role = "user"; content = "你好，请用一句话介绍你自己。" }
  )
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
  -Uri "https://你的中转站域名/v1/chat/completions" `
  -Method Post `
  -ContentType "application/json" `
  -Headers @{ Authorization = "Bearer sk-你的APIKey" } `
  -Body $body
```

### Python 示例

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的APIKey",
    base_url="https://你的中转站域名/v1",
)

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[
        {"role": "user", "content": "你好，请用一句话介绍你自己。"}
    ],
)

print(response.choices[0].message.content)
```

> `gpt-5.5` 只是示例模型名。你能使用哪些模型，请以 `/available-channels` 和后台模型列表为准。

## 查看用量和余额

使用过程中，你可以随时查看：

- `/dashboard`：账户概览、余额、快捷入口。
- `/usage`：请求记录、模型用量、费用明细。
- `/keys`：每个 API Key 的今日用量、总用量、额度进度和状态。
- `/key-usage`：不登录也可用 API Key 查询用量，适合给团队成员自查。
- `/orders`：查看充值或订阅订单。
- `/redeem`：查看兑换历史。

如果某个 Key 用量异常，可以在 `/keys` 页面先禁用它，再创建新 Key。

## 常见问题

### 兑换码不能用怎么办？

请确认兑换码没有多复制空格、没有大小写错误、没有过期，也没有被使用过。如果仍然失败，请截图发给客服。

### 余额到账了，为什么工具还是不能调用？

请检查 `/keys` 页面是否已经创建 API Key，并确认 Key 已分配分组。没有分组的 Key 不能正确展示对应使用配置。

### 为什么提示 401 或 Key 无效？

通常是 API Key 复制错了、Key 已禁用、Key 已删除、Key 过期，或者请求头没有写成 `Authorization: Bearer sk-你的APIKey`。

### 为什么提示模型不存在？

模型名必须和后台开放的模型名一致。请在 `/available-channels` 或「使用密钥」弹窗里复制模型名，不要手打猜测。

### 为什么请求超时或失败？

可以先看 `/monitor` 渠道状态。如果某个渠道临时异常，可以切换到其他可用渠道，或联系客服确认当前模型状态。

### 可以把一个 Key 给很多人用吗？

不建议。建议按人、按工具、按项目创建不同 Key，并设置额度限制。这样更容易查用量，也能在泄露时单独禁用。

### 我需要 VPN 吗？

正常使用我们的网站和 API 中转服务时，通常不需要你自己准备 VPN。你只需要能访问我们提供的网站域名和 API 地址。

## 安全使用提醒

- 不要公开 API Key。
- 不要把 Key 写进公开 GitHub 仓库。
- 不要在截图、直播、录屏里完整展示 Key。
- 给服务器使用的 Key 建议设置 IP 白名单。
- 给临时测试使用的 Key 建议设置有效期和额度限制。
- 发现异常用量时，先禁用旧 Key，再联系平台客服。
- 不要使用本服务生成、传播或处理违法违规内容。
