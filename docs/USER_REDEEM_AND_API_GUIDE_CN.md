# 中转站新手使用说明书

适用人群：第一次使用 API、中转站、兑换码或大模型工具的新用户。

本文会带你完成 4 件事：

1. 注册并登录中转站账号。
2. 使用兑换码兑换额度。
3. 获取并保存 API URL 和 API Key。
4. 在工具或代码里调用大模型。

> 本文里的 `https://你的中转站域名`、`sk-你的APIKey`、`gpt-5.5` 都是示例。实际填写时，请以平台后台展示的地址、密钥、模型名称和价格为准。

## 一分钟快速上手

如果你只想先跑通一次，请按这个顺序操作：

1. 打开中转站网址：`https://你的中转站域名`
2. 注册账号并登录。
3. 进入「兑换码」「充值」或「余额」页面，输入兑换码并确认兑换。
4. 进入「API Key」「令牌」或「密钥」页面，创建并复制 API Key。
5. 找到平台提供的 API URL，通常类似：`https://你的中转站域名/v1`
6. 在你的工具里填写：
   - Base URL / API URL：`https://你的中转站域名/v1`
   - API Key：`sk-你的APIKey`
   - Model / 模型：例如 `gpt-5.5`，或后台模型列表里的其他模型
7. 发送一句「你好」，能收到回复就说明配置成功。

## 第一步：注册账号

1. 打开中转站官网或客服提供的注册链接。
2. 点击「注册」「Sign up」或「创建账号」。
3. 按页面要求填写邮箱、手机号或用户名。
4. 设置密码。建议使用不低于 8 位的密码，并混合字母、数字和符号。
5. 如果页面要求验证码，请按提示完成邮箱验证、短信验证或图形验证。
6. 注册成功后，回到登录页输入账号和密码登录。

注册完成后，建议先检查 3 个地方：

- 账号是否已经登录成功。
- 后台是否能看到「余额」「充值」「兑换码」等入口。
- 后台是否能看到「API Key」「令牌」「密钥」或「开发者」入口。

## 第二步：使用兑换码兑换额度

兑换码用于把平台赠送或购买的额度充入你的账号。

1. 登录中转站后台。
2. 找到「兑换码」「礼品码」「充值」「余额」或类似入口。
3. 将兑换码完整复制进去。
4. 点击「兑换」「确认」「提交」。
5. 回到「余额」或「用量」页面，确认额度是否到账。

兑换时请注意：

- 兑换码可能区分大小写，复制时不要漏掉字符。
- 不要在兑换码前后多复制空格。
- 每个兑换码通常只能使用一次。
- 如果提示「已使用」「已过期」「不存在」，请截图并联系平台客服。
- 如果兑换成功但余额没变化，可以刷新页面，或稍等几分钟后再检查。

## 第三步：理解 URL 和 Key

调用大模型时，最常用的是两个信息：URL 和 Key。

| 名称 | 你需要填写什么 | 作用 |
| --- | --- | --- |
| API URL / Base URL | 通常类似 `https://你的中转站域名/v1` | 告诉工具把请求发到哪里 |
| API Key / Token / 密钥 | 通常类似 `sk-xxxxxxxx` | 证明这次请求属于你的账号 |
| Model / 模型 | 例如 `gpt-5.5`，以后台模型列表为准 | 告诉平台你想调用哪个模型 |

请像保管密码一样保管 API Key：

- 不要发到微信群、论坛、公开代码仓库或截图里。
- 不要把同一个 Key 给太多人共用。
- 如果怀疑 Key 泄露，立刻在后台删除旧 Key，并创建新 Key。
- 如果团队多人使用，建议给不同成员创建不同 Key，方便排查用量。

## 第四步：创建并复制 API Key

1. 登录中转站后台。
2. 进入「API Key」「令牌」「密钥」或「开发者」页面。
3. 点击「创建 Key」「新建密钥」或类似按钮。
4. 给 Key 起一个容易识别的名字，例如：
   - `my-laptop`
   - `cursor-work`
   - `server-test`
5. 复制新生成的 API Key，并保存到安全位置。
6. 如果后台只在创建时显示一次 Key，请务必当场复制保存。

## 第五步：在工具里填写 URL 和 Key

大多数支持 OpenAI 兼容接口的工具都会有类似配置项：

- API Key
- Base URL
- API URL
- Endpoint
- Model

常见填写方式如下：

| 配置项 | 示例填写 |
| --- | --- |
| Base URL / API URL | `https://你的中转站域名/v1` |
| API Key | `sk-你的APIKey` |
| Model | `gpt-5.5` 或后台模型列表中的模型 ID |

如果工具要求填写完整接口地址，可以填写：

```text
https://你的中转站域名/v1/chat/completions
```

如果工具要求填写 Base URL，通常只填写到 `/v1`：

```text
https://你的中转站域名/v1
```

## Windows PowerShell 测试示例

把下面命令里的域名、Key 和模型名换成你自己的：

```powershell
$body = @{
  model = "gpt-5.5"
  messages = @(
    @{ role = "user"; content = "你好，请用一句话介绍你自己。" }
  )
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
  -Uri "https://你的中转站域名/v1/chat/completions" `
  -Method Post `
  -ContentType "application/json" `
  -Headers @{ Authorization = "Bearer sk-你的APIKey" } `
  -Body $body
```

看到模型返回内容，就说明 URL、Key 和模型名配置成功。

## Python 调用示例

如果你的工具或项目使用 OpenAI 兼容 SDK，可以这样写：

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的APIKey",
    base_url="https://你的中转站域名/v1",
)

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[
        {"role": "user", "content": "你好，请用一句话介绍你自己。"}
    ],
)

print(response.choices[0].message.content)
```

## 使用中转站的优势

### 1. 不用自己折腾 VPN 或海外网络

很多用户直接访问海外大模型服务时，会遇到网络不稳定、连接失败或配置复杂的问题。使用中转站后，你只需要访问平台提供的 API URL，通常不需要自己单独准备 VPN 或海外网络环境，就能调用大模型。

### 2. 一个入口调用多种大模型

中转站可以把多个模型入口集中到一个后台里。你可以按需使用 OpenAI 的 ChatGPT-5.5 / GPT-5.5 系列，以及平台支持的其他模型。实际开放哪些模型、模型 ID 怎么写、价格是多少，请以后台模型列表为准。

### 3. 对 OpenAI 兼容工具更友好

很多开发工具、聊天客户端、IDE 插件和自动化工具都支持 OpenAI 兼容接口。只要工具允许填写自定义 Base URL 和 API Key，通常就可以接入中转站。

### 4. 余额、用量和成本更清楚

后台通常可以查看余额、充值记录、兑换记录和调用用量。这样你能知道额度花在哪里，也能更容易控制成本。

### 5. 更适合团队和多工具使用

你可以为不同工具或成员创建不同 API Key。例如一个 Key 给开发工具，一个 Key 给测试服务器，一个 Key 给团队成员。后续如果某个 Key 不再使用，可以单独删除，不影响其他 Key。

### 6. 降低账号和接口维护成本

用户不用分别研究多个模型厂商的账号、充值、接口格式和网络配置。中转站会把常用能力集中起来，让新用户更容易上手。

## 常见问题

### 兑换码输入后提示无效怎么办？

先检查是否复制错字符、是否多了空格、是否大小写错误。如果仍然无效，截图联系平台客服。

### 为什么提示余额不足？

可能是兑换码没有到账、余额已经用完，或当前模型单价较高。请先检查后台余额和用量记录。

### 为什么提示 Key 错误或 401？

通常是 API Key 复制错了、Key 已删除、Key 前后有空格，或者请求头没有写成 `Authorization: Bearer sk-你的APIKey`。

### 为什么提示模型不存在？

模型名必须和后台模型列表一致。请进入模型列表复制模型 ID，不要凭感觉手动输入。

### 为什么工具连不上？

请检查 Base URL 是否填写到 `/v1`，域名是否写错，网络是否能打开中转站后台。如果工具有代理设置，也请检查代理是否影响请求。

### Key 可以发给别人吗？

不建议。Key 等同于你的额度使用凭证。别人拿到 Key 后产生的消耗，会计入你的账号。

## 安全提醒

- 不要公开 API Key。
- 不要把 Key 写进公开仓库。
- 不要在截图里暴露 Key。
- 定期查看用量记录，发现异常及时停用旧 Key。
- 只在可信工具里填写 URL 和 Key。
- 不要用平台进行违法、违规或侵犯他人权益的内容生成与调用。

## 给客服或管理员的信息

如果用户无法完成配置，可以让用户提供以下信息，方便排查：

1. 注册账号或邮箱。
2. 兑换码截图或兑换提示截图。
3. 后台余额截图。
4. 工具里的 Base URL 截图。
5. 工具里的模型名截图。
6. 报错信息截图。

请提醒用户：截图时务必遮挡 API Key，只保留前后少量字符用于识别即可。
